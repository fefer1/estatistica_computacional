Análise do Tempo de Permanência no Posto de Saúde

Método de estatística computacional para simulação de filas com prioridades

Fernanda Reis

O Posto de Saúde

Em um posto de saúde, temos um pronto-atendimento para os pacientes que chegam ao hospital. Os pacientes são classificados com pulseiras de acordo com a urgência do tratamento necessário.

  • O tempo da consulta depende da gravidade do quadro clínico identificado. Os pacientes são atendidos por ordem de prioridade, graus de urgência menor só são atendidos após os pacientes de grau de urgência maior.
  • Durante um plantão, com 8 horas de duração, temos 4 médicos atendendo em paralelo. Após o fim do plantão, caso ainda existam pacientes para serem atendidos, os mesmos serão atendidos pelos médicos do proximo plantão.

Funcionamento do Pronto-Atendimento

Em média, 15 pacientes chegam ao hospital por hora.

Objetivos

Ao analisar esse posto de saúde, queremos responder as seguintes perguntas, utilizando simulação de filas com prioridades:

1.

Qual o tempo médio que os pacientes de cada prioridade permanecem no hospital?

2.

Qual o tempo médio que um paciente fica no hospital, independente de sua prioridade?

Modelagem Estatística

  1. Chegada dos Pacientes:

    Asumimos que as chegadas seguem um processo de poisson \(N(t) \sim Poisson(15t)\) e o intervalo entre as chegadas segue uma distribuição exponencial \(T_{\text{chegada}} \sim \operatorname{Exp}(15)\).

  2. Prioridade dos Pacientes:

    A prioridade será classificada a partir de \(X \sim U(0,1)\):

    \[ \text{P}(x) = \begin{cases} \text{Azul}, & 0 \leq x \leq 0{,}40 \\ \text{Verde}, & 0{,}40 < x \leq 0{,}60 \\ \text{Amarela}, & 0{,}60 < x \leq 0{,}80 \\ \text{Laranja}, & 0{,}80 < x \leq 0{,}95 \\ \text{Vermelha}, & 0{,}95 < x \leq 1 \end{cases} \]

Modelagem Estatística

  1. Tempo de Atendimento:

    O tempo de consulta será gerado por uma distribuição exponencial com taxa determinada conforme sua classificação de prioridade.

    \[ T_{\text{consulta}} \sim \begin{cases} \operatorname{Exp}(6), & \text{se } P = \text{Azul} \\ \operatorname{Exp}(5), & \text{se } P = \text{Verde} \\ \operatorname{Exp}(4), & \text{se } P = \text{Amarela} \\ \operatorname{Exp}(2), & \text{se } P = \text{Laranja} \\ \operatorname{Exp}(1), & \text{se } P = \text{Vermelha} \end{cases} \]

Simulação Computacional

  1. Lei dos Grandes Números:

    À medida que aumenta o número de simulações independentes, a média dos resultados converge para o valor esperado do processo.

  2. Fila de Atendimento em Paralelo com Prioridade:

    Quando um médico fica disponível, seleciona o próximo paciente conforme a prioridade (maior gravidade clínica são atendidos antes dos menos graves).

  3. Encerramento do Plantão:

    Após o fim do plantão, novas chegadas são interrompidas. Os pacientes que ainda aguardam atendimento permanecem na fila até serem atendidos pelos médicos do próximo plantão.

Simulação Computacional

modelagem_estatistica <- function(){
  
  fim_plantao=8

  #vetor de chegadas:
  t=0
  t1=0
  i=1
  fim=FALSE

  #gerar chegadas durante o plantão
  while(!fim){
    t1=t1+rexp(1,15)
    t[i]=t1
  
    if(t[i]>=fim_plantao){
      fim=TRUE
      t=t[1:i-1]
    }
    i=i+1
  }

  #vetor pulseiras por chegadas:
  p=numeric(length(t))
  for (i in 1:length(t)){
    c=runif(1)
    if(c<=0.4){
      p[i]=1
    } else if(c<=0.6){
      p[i]=2
    } else if(c<=0.8){
      p[i]=3
    } else if(c<=0.95){
      p[i]=4
    } else {
      p[i]=5
    }
  }

  #vetor de duracao do atendimento por pulseira:
  a=numeric(length(t))
  for (i in 1:length(p)){
    if(p[i]==1){
      a[i]=rexp(1,6)
    } else if(p[i]==2){
      a[i]=rexp(1,5)
    } else if(p[i]==3){
      a[i]=rexp(1,4)
    } else if(p[i]==4){
      a[i]=rexp(1,2)
    } else {
      a[i]=rexp(1,1)
    }
  }
  
  return(list(t=t, p=p, a=a))
}

Simulação Computacional

simulacao<-function(t,p,a){
  #vetor com o fim do atendimento por paciente:
  fa=rep(NA, length(t))

  #vetor de status dos pacientes no posto de saude: 
  # 0 = não chegou
  # 1 = aguardando
  # 2 = em atendimento
  # 3 = atendido
  s=rep(0, length(t))

  #vetor de medicos 
  medicos=rep(Inf,4) # Inf = médico livre

  #vetor de pacientes por médicos
  pacientes_medicos=rep(Inf,4) # Inf = médico sem paciente 

  while (min(s)!=3){ #enquanto todos os pacientes não forem atendidos
  
    #se ainda existem novos eventos de chegada
    if(any(s == 0)){
      t_chegada = min(t[s == 0]) #menor evento de chegada
      i_chegada = which(s == 0 & t == t_chegada) #paciente com menor chegada
    } else {
      t_chegada = Inf
      i_chegada = NA
    }
  
    t_termino=min(medicos) #menor evento de termino de atendimento
  
    #se evento for chegada de pacientes
    if(min(t_chegada,t_termino)==t_chegada){
      
        #se há pelo menos um medico disponível
        if(max(medicos)==Inf){ 
        
          #verifica se não existem pacientes na fila ou chegada é prioritária à quem está na fila
          if(sum(s==1)==0 || p[i_chegada]>max(p[s==1])){
      
            #identificamos o medico disponivel
            md=min(which(medicos==Inf))
      
            #colocamos o tempo de atendimento desde a chegada no primeiro indice de médico disponivel
            medicos[md]=t_chegada+a[i_chegada] 
      
            #colocamos o paciente que o médico está atendendo
            pacientes_medicos[md]=i_chegada
      
            #atualizamos o status do paciente que chegou para em atendimento
            s[i_chegada]=2
        
          #se há pacientes na fila e chegada não é prioritária à quem está na fila
          } else {
          
            #verifica a maior prioridade de quem está aguardando na fila 
            prioridades_fila=which(s==1 & p==max(p[s==1]))
      
            #avalia das prioridades aquele que chegou primeiro
            f=prioridades_fila[which.min(t[prioridades_fila])]
      
            #atualiza o status do paciente que chegou para aguardando na fila
            s[i_chegada]=1
          
            #identificamos o medico disponivel
            md=min(which(medicos==Inf))
      
            #colocamos o tempo de atendimento desde a chegada no primeiro indice de médico disponivel
            medicos[md]=t_chegada+a[f] 
      
            #colocamos o paciente que o médico está atendendo
            pacientes_medicos[md]=f
      
            #atualizamos o status do paciente que estava aguardando para em atendimento
            s[f]=2
          
          }
        #se nenhum médico está disponivel
        } else { 
        
          #atualizamos o status do paciente que chegou para aguardando
          s[i_chegada]=1
        }
      
    } else { #se evento for terminar atendimento
    
      #identifica qual medico terminou o atendimento
      mf=min(which(medicos==t_termino))
    
      #atualiza o status do paciente finalizou o atendimento
      s[pacientes_medicos[mf]]=3
    
      #define o horario do fim do atendimento do paciente
      fa[pacientes_medicos[mf]]=t_termino
    
      #se não há pacientes aguardando da fila
      if(sum(s==1)==0){
      
        #redefine o medico como livre
        medicos[mf]=Inf
      
        #remove o paciente que está sendo atendido pelo medico
        pacientes_medicos[mf]=Inf
      
      #se há pacientes aguardando na fila  
      } else {
        #verifica a maior prioridade de quem está aguardando na fila 
        prioridades_fila=which(s==1 & p==max(p[s==1]))
      
        #avalia das prioridades aquele que chegou primeiro
        f=prioridades_fila[which.min(t[prioridades_fila])]
      
        #colocamos o tempo de atendimento do proximo da fila desde o último fim de atendimento
        medicos[mf]=t_termino+a[f]
      
        #colocamos o paciente que o médico está atendendo
        pacientes_medicos[mf]=f
      
        #atualizamos o status do paciente que entrou para atendimento
        s[f]=2
      }
    }
  }
  
  permanencia = (fa - t)*60

  media_geral = round(mean(permanencia),2)

  media_pulseira = round(tapply(permanencia, factor(p, levels=1:5), mean),2)
  qtd_pulseira = table(factor(p, levels=1:5))

  return(c(geral=media_geral, media_pulseira, qtd_pulseira))
}

Simulação Computacional

replicacoes<-function(n){
  #gera matrix para salvar dados da simulação
  resultados = matrix(NA, nrow=n, ncol=11)

  for(i in 1:n){
    #gera os vetores de chegadas, pulseiras e duração de atendimentos
    dados = modelagem_estatistica()
    #salva o resultado da simulação por linha
    resultados[i,] = simulacao(dados$t,dados$p,dados$a)
  }
  return(resultados)
}

Tempo Médio de Permanência

O tempo médio de permanência no posto de saúde, independente da gravidade clínica, é de 66.4 minutos.

Gravidade Clínica e Tempo de Permanência

  • Gravidade Clínica Baixa \(\neq\) Menor Tempo de Permanência :

    Apesar de ser maior parcela dos pacientes (~40%), apresenta o maior tempo médio de permanência 105.7 minutos. Esse comportamento ocorre devido à menor prioridade na fila e à espera pelos atendimentos de maior gravidade.

  • Há um Ponto de Equilíbrio entre Frequência e Prioridade :

    Apesar da gravidade clínica média representar uma parcela significativa dos pacientes (~20%), sua prioridade de atendimento permite que os pacientes avançem na fila, resultando no menor tempo médio de permanência 32.2 minutos.

Gravidade Clínica e Tempo de Permanência

  • Baixa Frequência \(\neq\) Baixo Impacto no Tempo de Permanência:

    Apesar das gravidades clínicas alta e muito alta representarem uma pequena parcela dos pacientes (15% e 5%), demandam atendimentos mais longos e possuem alta prioridade de atendimento, impactando a disponibilidade médica e o tempo de espera dos demais pacientes.

  • Composição do Tempo Médio Geral de Permanência:

    O tempo médio geral de permanência reflete a combinação entre a espera dos pacientes menos prioritários e o consumo de recursos pelos atendimentos mais longos, ocultando diferenças significativas entre gravidades clínicas.
